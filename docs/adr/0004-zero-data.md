# ADR 0004: Zero Data Collection

Status: Accepted (2026-10-13)

## Decision
Neither the tool nor the website collects data. No telemetry, update checks, accounts, forms, cookies, analytics or server logs. Reports stay on the user's machine. The only public channel is GitHub.

## Consequences
No usage statistics; no way to contact users about issues except public advisories and release notes. In exchange there is no personal data to protect, leak or regulate.
