# ADR 0005: Non-Commercial Licence With Own-Use Permission

Status: Accepted (2026-10-13)

## Decision
PolyForm Noncommercial 1.0.0 plus the OpenVAPT Additional Permission: anyone, including companies, may use the software on their own machines for their own use; providing services, selling and other commercial activity are not permitted.

## Consequences
The code is fully public but the project is described as source-available rather than OSI open source. Permissive dependencies remain compatible.
