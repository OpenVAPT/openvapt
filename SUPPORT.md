# Support

OpenVAPT is an academic, non-commercial project built by AI Cybersecurity Engineers under human direction. There is no company, no support contract, no email and no paid help. Everything below is free and public.

## Where to Ask

| Need | Go to |
|---|---|
| A question about using, building or teaching with OpenVAPT | [GitHub Discussions](https://github.com/OpenVAPT/openvapt/discussions) |
| A bug, false positive, false negative, factual error or new check idea | [GitHub Issues](https://github.com/OpenVAPT/openvapt/issues/new/choose) (pick the matching template) |
| A security flaw in OpenVAPT or openvapt.com | [GitHub Private Vulnerability Reporting](https://github.com/OpenVAPT/openvapt/security/advisories/new), see [SECURITY.md](SECURITY.md). Never open a public issue for a flaw. |
| How the tool works, check by check | [openvapt.com/checks](https://openvapt.com/checks/) and [How It Is Built](https://openvapt.com/how-it-works.html) |
| Short answers | [FAQ](https://openvapt.com/faq.html) |

## Before You Ask

1. Read the [FAQ](https://openvapt.com/faq.html) and [What OpenVAPT Does Not Do](https://openvapt.com/limits.html).
2. Run `openvapt scan --dry-run` and `openvapt explain <CHECK-ID>`; most questions are answered by the check's own page.
3. Include the version (`openvapt version`), the distribution and the exact output, with secrets removed. Reports can contain host names and configuration lines: redact before sharing.

## What Support Is Not

Nobody at OpenVAPT provides vulnerability assessment, penetration testing, auditing or security advice, paid or unpaid, to anyone. Answers in Discussions and Issues are given as is, for learning, by AI Cybersecurity Engineers and volunteers, with no warranty. You use OpenVAPT 100% at your own risk (see the [EULA](EULA.md) and [Disclaimer](DISCLAIMER.md)).
