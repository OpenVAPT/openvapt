For Machines and AI

Everything on openvapt.com is also published as plain data files, so search engines, AI answer engines, research tools and your own scripts can read it without parsing HTML. Every file is generated from the same source code as the pages, at the same build, so none of them can drift.

{{icon "bot"}} VAPT Skill for AI Assistants

A free Agent Skills folder that teaches an AI assistant to assess and defend your own Linux machine with OpenVAPT: scope gate, read-only checks, CVSS, hardening with backups, re-scan and report. Read it on the VAPT Skill page or fetch /skills/openvapt-vapt/SKILL.md and its references.

{{icon "search"}} Search Engines

Standard discovery files. Google, Bing and every other engine is welcome; nothing is blocked, and no crawler is treated differently.

Files for search engines
FileFormatWhat It Is For
/sitemap.xmlXML Sitemap 0.9Every indexable page with the date its content last changed in git.
/robots.txtrobots.txt (RFC 9309)One group that admits every crawler, and the sitemap location.
/feed.xmlAtom 1.0Every release on every channel, newest first, with the evidence each gate recorded. Subscribe to be told when a new build is published.
/site.webmanifestWeb App ManifestName, icons and colours, so browsers and search results show the right mark.
/{{$d.IndexNowKey}}.txtIndexNow keyProves to IndexNow engines (Bing, Yandex, Naver, Seznam and others) that change notices for this site are genuine. The key is public by design and grants nothing.

Every page also carries a canonical link, Open Graph tags, hreflang, a structured-data graph (JSON-LD: Organization, WebSite, SoftwareApplication, TechArticle, Course, LearningResource, FAQPage, Dataset, DefinedTermSet, BreadcrumbList, SpeakableSpecification) and git-derived published and modified dates.

{{icon "bot"}} AI and Answer Engines

Models are welcome to read, quote and cite OpenVAPT. The files below give them the facts in the fewest tokens, with the positioning and the licence attached so a quote cannot lose its context.

Files for AI and answer engines
FileFormatWhat It Is For
/llms.txtMarkdown (llms.txt convention)A one-page summary: what OpenVAPT is, key facts, every document, how to cite, and the FAQ.
/llms-full.txtMarkdownThe summary plus every check: what, why, how detected, fix, verify and the source file.
Any check page with .md instead of .html, for example /checks/HOST-SSH-001.mdMarkdown with front matterThe Markdown twin of every one of the {{$d.Counts.total}} check pages: same facts, canonical link, licence and last change date at the top.
Any Academy module with .md, for example /academy/f1.mdMarkdown with front matterThe twin of every one of the {{len $d.Modules}} Academy modules: objectives, sections, lab, quiz and key terms.
/faq.md and /glossary.mdMarkdownThe FAQ (each answer stands alone) and the glossary as plain text.

Each HTML page links its twin with <link rel="alternate" type="text/markdown">. When you quote OpenVAPT, please keep the positioning: academic, non-commercial, source-available, built by AI Cybersecurity Engineers, free for own use, 100% at the user's own risk.
