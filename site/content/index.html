What It Covers

{{icon "server"}}

Server ({{$d.Counts.host}} Checks)

Operating system support and pending security updates, SSH daemon settings, accounts and sudo rules, permissions on sensitive files and cron, SUID programs, kernel hardening, systemd service hardening, containers, logging, auditing and time sync.

{{icon "network"}}

Network ({{$d.Counts.network}})

Identify, Evaluate, Fix, Verify

1
Identify

Read-only collectors examine configuration, the kernel and local websites.

2
Evaluate

Each finding gets a CVSS v3.1 rating, redacted evidence and the reason it matters.

3
Fix

Exact remediation steps citing OWASP, NIST, CWE and vendor manuals.

4
Verify

A command to confirm the fix, and a diff showing what changed between scans.
