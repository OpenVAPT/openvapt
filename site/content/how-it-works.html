Design in One Paragraph

Checks are small Go files that describe one weakness and how to detect it. They never touch the operating system directly. Instead they receive a read-only System, whose network access is confined by the scope guard to this machine. The engine runs the checks, redacts secrets and writes the report to the local disk. The same checks run against simulated lab servers in the tests, which proves each one detects its weakness and stays silent once it is fixed.
