Download Only

Install and verify now, scan later when you are ready. Nothing is scanned and nothing needs root.

{{template "copybox" $i.DownloadOnly}}

What It Does

  1. Checks the machine is Linux on amd64 or arm64.
  2. Reads the public channel list and picks the most stable channel with a release. While there is no Stable release, it says which pre-release channel it uses and warns you.
  3. Downloads the binary and SHA256SUMS from GitHub Releases over HTTPS only.
  4. Refuses to install unless the SHA-256 checksum matches; also verifies the Sigstore signature when cosign is installed.
  5. Installs openvapt to ~/.local/bin without root, and prints the next steps.

What You See

OpenVAPT installer
  release vX.Y.Z, linux/amd64
  checksum verified (sha256 64 hex digits)
  installed /home/you/.local/bin/openvapt

Installed (Download Only). Nothing has been scanned.

Where Reports Go

Nowhere yet: no scan runs. When you scan later, each scan writes a new folder ~/openvapt-reports/<UTC time>/ in the home folder of the user who runs it (root's home folder with sudo), unless you choose one with --out.

Time and Permissions

Under a minute. No root, no account, nothing sent anywhere except the downloads from GitHub.

Download and Scan

Install, verify and assess this machine in one go, with every report written for you. Run it in a terminal on the machine itself: the scan needs you to type I ACCEPT.

{{template "copybox" $i.DownloadScan}}

What It Does

  1. Everything Download Only does: picks the release, verifies the checksum (and the signature with cosign) and installs without root.
  2. Starts a read-only scan of this machine only. Every connection stays on 127.0.0.1.
  3. The scan shows the acknowledgements and waits for you to type I ACCEPT on the terminal, even when the installer is piped. The installer never answers for you; with no terminal it refuses to scan.
  4. Writes all four reports, signed with your local key: report.html, report.json, report.sarif and report.md.
  5. Prints the severity summary, the exit code and what it means, every report path, and how to open the HTML report.

What You See

type I ACCEPT to continue (anything else cancels; nothing is stored): I ACCEPT
Scanning this machine with N checks (read-only, local only)...
Scan finished.
Summary: Critical n, High n, Medium n, Low n, ...
Exit code 3: findings at or above High severity were found
Reports (only on this machine, readable only by you):
  /home/you/openvapt-reports/20261014T074600Z/report.html

Where Reports Go

A new folder ~/openvapt-reports/<UTC time>/, readable only by you (mode 0700). It is never reused or written over. Choose another new folder with --out DIR.

Time and Permissions

Usually one to five minutes. By default the scan runs as you, so checks that need protected files are reported as Incomplete. For full coverage add --sudo: only the scan runs with sudo (it may ask for your password), the install does not, and the reports are given back to you.

Full Coverage

{{template "copybox" $i.ScanSudo}}

More options: --open opens the HTML report with xdg-open, only in a desktop session; --dry-run installs and then previews every file, command and request a scan would use, without scanning. Exit codes: 0 completed with nothing at or above High, 3 findings at or above High, 4 incomplete coverage, 5 error or cancelled, 6 the report could not be written.

Build From Source (Most Transparent)

You run exactly the code you can read, it needs nothing but Go, and building it is part of learning how it works. You need Go 1.26 or newer; go.mod pins the Go 1.26.9 toolchain and Go downloads it automatically if needed.

# 1. Get the source
git clone https://github.com/OpenVAPT/openvapt.git
cd openvapt

# 2. Read it (start with README.md, internal/scope and internal/sys)

# 3. Run the tests, including the simulated lab tests
go test ./...

# 4. Build a single static binary
CGO_ENABLED=0 go build -trimpath -o openvapt ./cmd/openvapt

# 5. Read the acknowledgements again, then check the version
./openvapt terms
./openvapt version

To build exactly a released version, check out its tag first, for example git checkout v{{$d.CiteVersion}} (the newest released build; see Release Channels for every channel). To build the same bytes as the official release binary, use the same Go version and flags as the release (shown in its release notes and in the Makefile):

git checkout v{{$d.CiteVersion}}
make release VERSION=v{{$d.CiteVersion}}
sha256sum dist/release/openvapt_linux_amd64   # compare with the published SHA256SUMS

Try It Safely First

openvapt demo                    # scans a simulated vulnerable server, in memory
openvapt scan --dry-run          # lists every file, command and request a real scan would use
openvapt learn                   # the OpenVAPT Academy, offline
openvapt explain HOST-SSH-001    # documentation for one check

Scan Your Own Linux Machine

sudo openvapt scan

Before every scan the tool shows the acknowledgements again and continues only when you type I ACCEPT (or you pass --accept-terms for automation, which counts as the same acceptance). Running as root lets checks read protected files such as /etc/shadow; without root those checks are skipped or marked Incomplete. Reports go to a new private folder ~/openvapt-reports/<UTC time>/ in the home folder of the user running the scan (root's with sudo), or to the folder you name with --out. After the scan OpenVAPT lists every report file and how to open the HTML report. Exit codes: 0 success, 2 invalid arguments, 3 Critical or High findings, 4 incomplete coverage, 5 scan errors, 6 report write failure.

Cite OpenVAPT

If OpenVAPT helps your coursework, thesis, paper or project, please cite the version you used (openvapt version). Copy a ready-made reference from How to Cite OpenVAPT or read Citing OpenVAPT.

Uninstall

OpenVAPT installs nothing beyond its own binary. Delete the binary (rm ~/.local/bin/openvapt if you used the installer) and your report folders (~/openvapt-reports). If you signed reports, also delete ~/.config/openvapt/report-key.
