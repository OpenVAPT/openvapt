Download and Run OpenVAPT

Free for anyone, including companies, to run on their own Linux machines for their own use. Read the EULA first: you carry 100% of the risk.

{{icon "info"}}Public releases start once the GitHub repository opens. Until then, build from source as shown below. Each release will publish SHA-256 checksums and signatures produced by the public build pipeline.

Build From Source

You need Go 1.22 or newer. OpenVAPT uses only the Go standard library, so nothing else is downloaded.

git clone https://github.com/openvapt/openvapt.git
cd openvapt
go test ./...
CGO_ENABLED=0 go build -trimpath -o openvapt ./cmd/openvapt
./openvapt version

Try It Safely First

./openvapt demo                    # scans a simulated vulnerable server, in memory
./openvapt scan --dry-run          # lists every file, command and request a real scan would use
./openvapt explain HOST-SSH-001    # documentation for one check

Scan Your Own Linux Machine

sudo ./openvapt scan --out ~/openvapt-report

Running as root lets checks read protected files such as /etc/shadow; without root those checks are skipped. The scan asks you to accept the terms each time (nothing is stored), writes the report only to the folder you choose with private permissions, and exits with code 3 when Critical or High findings exist, which is useful in automation.

Verify a Release Download

sha256sum -c openvapt_linux_amd64.sha256
cosign verify-blob --certificate-identity-regexp 'https://github.com/openvapt/openvapt/' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --bundle openvapt_linux_amd64.sigstore.json openvapt_linux_amd64

Uninstall

OpenVAPT installs nothing. Delete the binary and your report folders. If you signed reports, also delete ~/.config/openvapt/report-key.
